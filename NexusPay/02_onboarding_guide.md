# Гайд по онбордингу нового разработчика

**Версия документа:** 1.8  
**Владелец:** Platform-SRE & HR  
**Связанные документы:** `01_company_overview.md`, `03_security_policy.md`

## 1. Первый рабочий день
После подписания документов сотрудник получает учетную запись в корпоративном SSO (Keycloak). Логин формируется по шаблону `i.ivanov@nexuspay.ru`.

### Обязательные шаги в первые 24 часа:
1. Настроить двухфакторную аутентификацию (2FA) через приложение TOTP (Google Authenticator или Яндекс.Ключ).
2. Получить доступ к корпоративному VPN (WireGuard) через портал `vpn.nexuspay.internal`.
3. Пройти инструктаж по информационной безопасности (см. `03_security_policy.md`).

## 2. Настройка локального окружения
Для работы с микросервисами требуются:
* **Docker Desktop** или **OrbStack** (минимум 16 ГБ RAM выделено под контейнеры).
* **Go 1.23+** (основной язык бэкенда) или **Python 3.12+** (для команды Risk-AI).
* **kubectl** и **helm** для работы со стейджинг-кластерами.

### Локальный запуск инфраструктуры
Базовые зависимости (PostgreSQL 16, Kafka, Redis) поднимаются единым скриптом из репозитория `nexus-infra-local`:
```bash
git clone git@gitlab.nexuspay.internal:platform/nexus-infra-local.git
cd nexus-infra-local
make up-core
```

## 3. Испытательный срок
Длительность испытательного срока составляет **3 месяца**. На второй день тимлид назначает бадди (наставника) и ставит первую задачу с тегом `good-first-issue`.
