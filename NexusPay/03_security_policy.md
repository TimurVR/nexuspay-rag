# Политика информационной безопасности (ИБ)

**Версия документа:** 3.1  
**Владелец:** Отдел ИБ (CISO: Андрей Крылов)  
**Критичность:** Обязательно к исполнению всеми сотрудниками

## 1. Классификация данных
В «НексусПэй» приняты 4 уровня конфиденциальности:
* **Public:** публичная документация API, маркетинговые материалы.
* **Internal:** внутренние регламенты, архитектура, неперсонализированные метрики.
* **Confidential:** исходный код, финансовая отчетность, ключи API клиентов.
* **Restricted (PCI DSS):** номера банковских карт (PAN), CVV, персональные данные (ПДн) пользователей.

## 2. Работа с секретами и паролями
* **Запрещено** хранить токены, пароли и приватные ключи в Git-репозиториях (включая `.env` файлы в приватных ветках).
* Все секреты хранятся исключительно в **HashiCorp Vault** (`vault.nexuspay.internal`).
* Ротация токенов доступа к production-базам происходит автоматически каждые **30 дней**.

## 3. Доступ к Production-среде
Прямой SSH-доступ к серверам production закрыт. Для диагностики инцидентов используется механизм временного повышения прав (**Break-Glass Access**) через Telegram-бота `@NexusSecOpsBot` с обязательным указанием номера тикета в Jira. Время действия сессии — **60 минут**.

## 4. Требования к рабочим станциям
1. Шифрование диска (FileVault для macOS, LUKS для Linux) должно быть включено.
2. Автоблокировка экрана при бездействии — не более **5 минут**.
3. Запрещено использование публичных LLM-сервисов для анализа фрагментов кода, содержащих логику работы `ShieldGuard` или клиентские данные.
